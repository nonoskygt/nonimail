Cómo crear tu Client ID (una sola vez, ~10 min)
              
    
                
  1. Entrá a Google Cloud Console y creá un proyecto (por ejemplo "NoniMail").
    2. 
                
  2. En APIs y servicios → Biblioteca, habilitá la Gmail API.
    3. 
                
  3. En Pantalla de consentimiento de OAuth: tipo Externo, nombre de la app y tu correo. En Permisos agregá https://mail.google.com/.
    4. 
                
  4. En Público, tocá Publicar app (estado "En producción"). Si queda "En prueba", Google corta el acceso cada 7 días. No hace falta verificarla: es solo para vos.
    5. 
                
  5. En Credenciales → Crear credenciales → ID de cliente de OAuth, tipo App de escritorio. Copiá el Client ID y el Client Secret acá.
    6. 
                
  6. Tocá Conectar con Google. Google va a avisar "Google no verificó esta app": es la tuya, tocá Configuración avanzada → Ir a NoniMail y aceptá el acceso al correo.
    7.
